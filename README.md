# 宗亞工程師培訓｜專案工作區

公開首頁只介紹課程；實際專案內容必須登入、經管理者核准且取得該專案授權才能讀取。網站不收集或保存登入密碼，沿用 Sites 的 ChatGPT 身份驗證。

## 管理與協作

1. 管理者登入「成員與權限」，加入工程師實際登入信箱，設定啟用、建立專案及分享權限。
2. 建立專案後，於「分享／權限」指定專案負責人、可編輯或唯讀。
3. 負責人只有在管理者開放分享權限時，才能把該專案分享給其他已核准成員；無法授予管理者或新的專案負責人權限。
4. 複製連結不會授權。未核准、未指派或停用帳號無法讀取專案。
5. 每個專案分開儲存。衝突版本會拒絕覆蓋，原始版本與操作紀錄保留於資料庫。

## 保存與備份

網站的 D1 資料庫是工作中資料來源。每次儲存立即寫入專案與版本；Drive 是每案獨立的延續／備份副本，介面區分「已保存」與「待備份」。JSON包含專案與權限資料，MD用來閱讀。備份指向固定根資料夾，由管理者的連線執行，不要求工程師取得整個Drive根資料夾權限。

`/mcp` 提供擁有者限定的備份工具，適用有權限的助理或備份排程；每次都驗證平台身份與管理者身份。無法連線、校驗失敗或版本已變更，不會標示備份成功。具體自動化啟用狀態以工作區提示為準；功能發布不等於排程已連接或已成功執行。

## 執行環境

- `TRAINING_ADMIN_EMAIL`：平台驗證的管理者登入信箱，存於秘密環境設定。
- `PROJECT_ARCHIVE_ROOT`：指定Drive根資料夾ID，存於秘密環境設定。
- `DB`：Cloudflare D1。保留既有migration，新增變更另建migration。
- 不把真實人員、進度、權限、秘密設定或私人Drive網址提交到公開GitHub。
- 公開GitHub使用空白教材範本；正式網站使用獨立受控教材設定。
