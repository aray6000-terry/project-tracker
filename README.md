# 宗亞專案工程師培訓進度管理

24週／240小時的工程師養成追蹤工具，含182項任務欄位、六階段考核、四個實作站與八項核心能力。本公開儲存庫提供空白任務範本；正式網站教材另由管理者維護，不包含在本儲存庫。

## 使用入口

- 公開唯讀進度網頁：https://zongya-engineer-training-tracker.usb2688.chatgpt.site
- 完整教材：由網頁「教材與文件」開啟，存取仍依原文件權限。

GitHub提供網頁原始碼與預設任務範本。實際學員、分數、證據及進度保存在網站的資料庫，不提交到GitHub。完整MD教材另外保存於使用者指定的Google Drive，不在公開儲存庫散布。

## 功能

- 多專案／梯次與人員設定、按起訓日產生課程期限。
- 任務查詢、狀態、負責人、期限、實際時數、證據、覆核與備註。
- 完成任務須具備證據與覆核；受阻須記原因及下一步。
- 六階段加權評分與安全、文件、重大缺失、簽認條件。
- 結訓檢查四實作站與八核心能力，保留授權範圍。
- 雲端保存與衝突偵測、JSON備份還原、CSV匯出。

## 資料與權限

任何人可直接查看公開頁面，無須 ChatGPT 帳號。公開資訊限於專案／梯次名稱、起訓日、任務狀態、期限、累計時數與階段是否通過。請使用梯次或代碼命名，勿把個資放入專案名稱。

管理者登入後由平台可信身份與伺服器環境變數 `TRAINING_ADMIN_EMAIL` 比對授權；設定值只放執行環境，不提交程式。其他帳號與匿名訪客無法寫入。姓名、個別分數、備註、簽認、實際證據與內部文件連結只回傳給管理者，公開回應採明確欄位清單。

管理者按「儲存並更新公開進度」後，完整紀錄與公開摘要在同一資料庫交易儲存；訪客重新載入即可看到最新進度。PUT 檢查來源、資料結構及版本號，過期版本不覆蓋新紀錄。JSON 備份含私人資料，請保管於適當權限位置。

教材文件與程式沒有自動雙向同步。簽認欄是作業紀錄，不是數位簽章。資料庫 migration 在發布時套用，部署不清除既有資料。

## 本地開發

需要Node.js 22.13以上、pnpm 11。此專案基於Vinext與Cloudflare D1。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

執行檢查與建置：

```sh
node node_modules/typescript/bin/tsc --noEmit
node scripts/test-training.mjs
node scripts/test-public-api.mjs
pnpm build
```

修改資料表後執行`pnpm db:generate`，檢查生成SQL。既有migration不可修改；新增migration保留歷史。啟用本地D1須先按starter工作流程建置並套用SQL到本地資料庫。

新部署應建立自己的 Site 身份與 DB 綁定，設定管理者環境變數後，才可啟用編輯。若要提供公開檢視，須明確設定 Site 存取為 public；編輯仍保留平台登入與伺服器權限檢查。GitHub Pages只能執行靜態檔案，不能直接承載這個含D1與登入的服務端版本。

## 驗證

12項規則測試涵蓋清冊完整性、240小時、必要證據、分數、安全、簽認、實作／能力門檻、跨年期限、匯入格式及CSV公式字串。另有10項 API 測試，以真實記憶體 SQLite 與模擬可信身份驗證匿名讀取、未授權寫入拒絕、私人欄位隔離、公開更新、版本衝突與交易回滾。適用規則為建議培訓制度，須由公司主管核定。
