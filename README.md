# 宗亞專案工程師培訓進度管理

24週／240小時的工程師養成追蹤工具，含182項空白任務欄位、六階段考核、四個實作站與八項核心能力。

## 使用入口

- 私人進度網頁：https://zongya-engineer-training-tracker.usb2688.chatgpt.site
- 完整教材：由網頁「教材與文件」開啟，存取仍依原文件權限。

GitHub提供網頁原始碼與空白任務範本。實際學員、分數、證據及進度保存在私人網站的資料庫，不提交到GitHub。完整MD教材另外保存於使用者指定的Google Drive，不在公開儲存庫散布。

## 功能

- 多專案／梯次與人員設定、按起訓日產生課程期限。
- 任務查詢、狀態、負責人、期限、實際時數、證據、覆核與備註。
- 完成任務須具備證據與覆核；受阻須記原因及下一步。
- 六階段加權評分與安全、文件、重大缺失、簽認條件。
- 結訓檢查四實作站與八核心能力，保留授權範圍。
- 雲端保存與衝突偵測、JSON備份還原、CSV匯出。

## 資料與權限

以ChatGPT登入的Site內穩定使用者ID隔離資料。GET與PUT均需身份；PUT檢查來源、資料結構及版本號。資料庫migration在發布時套用，不在請求中建表。網頁目前只供擁有者使用，未提供多帳號共同簽核，簽認欄也不是數位簽章。

程式、Drive教材與動態資料庫沒有自動雙向同步。變更表單按「套用」後，仍需右上角「儲存到雲端」。部署新版本不清除資料庫資料。

## 本地開發

需要Node.js 22.13以上、pnpm 11。此專案基於Vinext與Cloudflare D1。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

執行檢查與建置：

```sh
node node_modules/typescript/bin/tsc --noEmit
node scripts/test-training.mjs
pnpm build
```

修改資料表後執行`pnpm db:generate`，檢查生成SQL。既有migration不可修改；新增migration保留歷史。啟用本地D1須先按starter工作流程建置並套用SQL到本地資料庫。

新部署應建立自己的Site身份與DB綁定，保留平台的登入整合；不得把私人站點改公開來略過登入。GitHub Pages只能執行靜態檔案，不能直接承載這個含D1與登入的服務端版本。

## 驗證

12項規則測試涵蓋清冊完整性、240小時、必要證據、分數、安全、簽認、實作／能力門檻、跨年期限、匯入格式及CSV公式字串。已檢查桌面總覽及任務編輯介面。適用規則為建議培訓制度，須由公司主管核定。

## 公開版本資料界線

`app/data/training.json`是空白範本，不包含內部培訓內容或私人文件URL。正式私人網站使用另外受控的教材設定；本公開版本不得直接覆蓋正式教材。範本中的182項僅為欄位結構，不代表實際指導清冊。
私人部署資料與公開程式庫不自動雙向同步，更新程式時需保留原先受控教材。
